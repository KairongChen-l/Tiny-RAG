## 1. 前置要求

- **Go**：1.21+（部分场景需要 CGO，按实际配置）
- **Flutter**：3.0+
- **Ollama**（可选但推荐本地调试）：用于 embedding/LLM
- **Docker + Docker Compose**（可选但推荐生产/集成）：用于 MySQL / Redis / Qdrant

## 2. 快速启动（本地开发）

### 2.1 一键脚本（如果仓库提供）

```bash
./scripts/start-all.sh
./scripts/stop-all.sh
```

> 若脚本不存在或不适用，请走下面的手动启动。

### 2.2 手动启动（推荐流程）

#### 终端 1：启动 Ollama

```bash
ollama serve

# 首次需要下载模型（示例）
ollama pull nomic-embed-text
ollama pull llama2
```

验证：

```bash
curl http://localhost:11434/api/tags
```

#### 终端 2：启动后端

```bash
cd /home/krc/RAG
go run ./cmd/server --config configs/config-ollama.yaml
```

验证：

```bash
curl http://localhost:8080/api/v1/health
```

#### 终端 3：启动 Flutter 前端

```bash
cd /home/krc/RAG/frontend/rag_flutter
flutter pub get

# 桌面（推荐）
flutter run -d linux

# 或 Web（不依赖 chrome 设备时可用）
flutter run -d web-server --web-port=3000
```

## 3. 基础设施（Docker Compose：MySQL / Redis / Qdrant）

如果你使用 **MySQL + Qdrant** 混合存储，建议用 Compose 启动：

```bash
cd /home/krc/RAG
docker-compose up -d
docker-compose ps
```

常用：

```bash
docker-compose logs -f
docker-compose down
```

Qdrant Dashboard（默认）：
- `http://localhost:6333/dashboard`

> 生产环境请务必为 MySQL/Redis 设置强密码与访问控制；必要时加资源限制与备份策略。

## 4. 后端配置选择（常见场景）

### 4.1 本地纯 Ollama

```bash
go run ./cmd/server --config configs/config-ollama.yaml
```

### 4.2 MySQL + Qdrant（生产/集成常用）

```bash
make run-config CONFIG=./configs/config-mysql-qdrant.yaml
```

验证：

```bash

```

## 5. 部署（概览）

### 5.1 直接运行（本机/VM）

```bash
cd /home/krc/RAG
go build -o bin/rag-server ./cmd/server
./bin/rag-server --config configs/config-ollama.yaml
```

### 5.2 Docker 运行（仅后端容器示例）

```bash
docker build -t rag-server:latest .
docker run -d -p 8080:8080 rag-server:latest
```

> 若需要外挂配置与数据目录，请自行挂载 `configs/` 与 `data/`。

### 5.3 systemd（示意）

在 Linux 服务器上可将后端进程托管到 systemd（略），核心是：固定工作目录 + ExecStart 指向二进制与配置路径 + Restart 策略。

## 6. 端到端测试（E2E）最小流程

### 6.1 启动所有组件

- 基础设施（如果需要）：`docker-compose up -d`
- 后端：`go run ./cmd/server --config ...`
- 前端：`flutter run -d linux`（或 web-server）

### 6.2 验证关键端点

```bash
curl http://localhost:8080/api/v1/health
curl http://localhost:8080/metrics
```

### 6.3 功能验证（面向用户）

- 打开前端
- 发送问题（确保能看到 loading -> 回复）

> 旧文档中的“Upload Document”按钮/弹窗路径可能已过时（前端已在往对话式 UI 迁移），以当前 UI 为准。

## 7. 常见问题（Troubleshooting）

### 7.1 Flutter 找不到 chrome 设备

改用 Linux 桌面或 web-server：

```bash
flutter run -d linux
flutter run -d web-server --web-port=3000
```

### 7.2 Flutter 没有配置 Linux 桌面支持

```bash
flutter config --enable-linux-desktop
flutter create --platforms=linux,web .
flutter pub get
flutter run -d linux
```

### 7.3 后端端口占用

```bash
lsof -i :8080
```
