# RAG系统完整运行指南

## 前置要求

- Go 1.21+
- Flutter SDK 3.0+
- Ollama（本地运行）
- Redis（可选，用于缓存和任务队列）

## 步骤1: 启动Ollama服务

### 1.1 检查Ollama是否已安装

```bash
ollama --version
```

如果未安装，请访问 https://ollama.ai 下载安装。

### 1.2 启动Ollama服务

```bash
# 启动Ollama服务（通常会自动启动）
ollama serve

# 或者如果Ollama已作为服务运行，检查状态
curl http://localhost:11434/api/tags
```

### 1.3 下载必要的模型

```bash
# 下载嵌入模型（用于文档向量化）
ollama pull nomic-embed-text

# 下载LLM模型（用于生成回答）
ollama pull llama2

# 或者使用其他模型
# ollama pull mistral
# ollama pull qwen2
```

### 1.4 验证Ollama运行状态

```bash
# 检查模型列表
ollama list

# 测试嵌入模型
curl http://localhost:11434/api/embeddings -d '{
  "model": "nomic-embed-text",
  "prompt": "test"
}'

# 测试LLM模型
ollama run llama2 "Hello"
```

## 步骤2: 配置后端

### 2.1 创建配置文件

```bash
cd /home/krc/RAG

# 使用Ollama配置
cp configs/config.yaml configs/config-ollama.yaml
```

### 2.2 编辑配置文件

编辑 `configs/config-ollama.yaml`，确保以下配置：

```yaml
embedding:
  provider: "ollama"
  ollama:
    base_url: "http://localhost:11434"
    model: "nomic-embed-text"
    dimensions: 768

llm:
  default_provider: "ollama"
  ollama:
    base_url: "http://localhost:11434"
    model: "llama2"
```

### 2.3 （可选）配置Redis

如果使用Redis缓存和任务队列：

```bash
# 启动Redis（如果未运行）
redis-server

# 验证Redis运行
redis-cli ping
# 应返回: PONG
```

在配置文件中启用Redis：

```yaml
embedding:
  cache:
    enabled: true
    type: "redis"
    ttl: 3600

job:
  queue_type: "redis"
```

## 步骤3: 启动后端服务器

### 3.1 编译服务器

```bash
cd /home/krc/RAG
go build -o bin/rag-server ./cmd/server
```

### 3.2 启动服务器

```bash
# 使用Ollama配置启动
./bin/rag-server --config configs/config-ollama.yaml

# 或者直接运行
go run ./cmd/server --config configs/config-ollama.yaml
```

### 3.3 验证后端运行

```bash
# 检查健康状态
curl http://localhost:8080/api/v1/health | jq '.'

# 应该返回类似：
# {
#   "success": true,
#   "data": {
#     "status": "healthy",
#     "components": {
#       "database": "ok",
#       "embedding": "ok",
#       "llm": "ok"
#     }
#   }
# }
```

## 步骤4: 启动Flutter前端

### 4.1 进入Flutter项目目录

```bash
cd /home/krc/RAG/frontend/rag_flutter
```

### 4.2 安装Flutter依赖

```bash
flutter pub get
```

### 4.3 检查Flutter环境

```bash
flutter doctor
```

### 4.4 运行Flutter应用

```bash
# Web平台（推荐用于开发）
flutter run -d chrome

# 或者指定端口
flutter run -d chrome --web-port=3000

# Windows平台
flutter run -d windows

# Linux平台
flutter run -d linux

# macOS平台
flutter run -d macos
```

### 4.5 配置API地址（如需要）

如果后端不在 `localhost:8080`，编辑 `lib/services/api_service.dart`：

```dart
static const String baseUrl = 'http://your-backend-host:8080/api/v1';
```

## 步骤5: 验证完整流程

- 嵌入向量已生成
- 检索和生成正常

## 快速启动脚本

创建 `scripts/start-all.sh`：

```bash
#!/bin/bash

echo "=== 启动RAG系统 ==="

# 1. 检查Ollama
echo "1. 检查Ollama..."
if ! curl -s http://localhost:11434/api/tags > /dev/null; then
    echo "错误: Ollama未运行，请先启动: ollama serve"
    exit 1
fi
echo "✓ Ollama运行中"

# 2. 启动后端
echo "2. 启动后端服务器..."
cd /home/krc/RAG
go run ./cmd/server --config configs/config-ollama.yaml > /tmp/rag-server.log 2>&1 &
BACKEND_PID=$!
sleep 3

if ! curl -s http://localhost:8080/api/v1/health > /dev/null; then
    echo "错误: 后端启动失败，查看日志: /tmp/rag-server.log"
    kill $BACKEND_PID 2>/dev/null
    exit 1
fi
echo "✓ 后端运行中 (PID: $BACKEND_PID)"

# 3. 启动Flutter前端
echo "3. 启动Flutter前端..."
cd frontend/rag_flutter
flutter run -d chrome > /tmp/flutter.log 2>&1 &
FLUTTER_PID=$!
echo "✓ Flutter启动中 (PID: $FLUTTER_PID)"

echo ""
echo "=== 启动完成 ==="
echo "后端: http://localhost:8080"
echo "前端: 查看Flutter输出"
echo ""
echo "停止服务:"
echo "  kill $BACKEND_PID $FLUTTER_PID"
```

## 常见问题

### Ollama连接失败

```bash
# 检查Ollama是否运行
ps aux | grep ollama

# 检查端口
netstat -tlnp | grep 11434

# 重启Ollama
pkill ollama
ollama serve
```

### 后端启动失败

```bash
# 检查端口占用
lsof -i :8080

# 查看日志
tail -f /tmp/rag-server.log

# 检查配置
cat configs/config-ollama.yaml
```

### Flutter运行失败

```bash
# 检查Flutter环境
flutter doctor -v

# 清理并重新获取依赖
flutter clean
flutter pub get

# 检查设备连接
flutter devices
```

### 文档上传失败

- 检查文件格式（支持 .md, .txt, .pdf）
- 检查文件大小（默认最大32MB）
- 查看后端日志中的错误信息

### 查询无响应

- 检查Ollama模型是否正确下载
- 检查后端健康状态
- 查看后端日志中的错误信息
- 确认文档已成功处理
