# Flutter 启动指南

## 快速开始

```bash
cd /home/krc/RAG/frontend/rag_flutter

# 1. 安装依赖
flutter pub get

# 2. 检查可用设备
flutter devices

# 3. 运行（选择其中一个）
flutter run -d linux              # Linux桌面（推荐）
flutter run -d web-server --web-port=3000  # Web模式
```

## 完整启动流程

完整的系统启动需要三个终端：

```bash
# 终端1: Ollama（如果未启动）
ollama serve

# 终端2: 后端（如果未启动）
cd /home/krc/RAG
go run ./cmd/server --config configs/config-ollama.yaml

# 终端3: Flutter前端
cd /home/krc/RAG/frontend/rag_flutter
flutter pub get
flutter run -d linux
```

## 验证

启动成功后，验证系统是否正常工作：

1. **后端健康检查**: `curl http://localhost:8080/api/v1/health`
2. **Flutter应用**: 应该自动打开窗口
3. **状态指示器**: 检查左侧抽屉底部的状态指示器（API、Embedding、LLM应该都是绿色）

## 常见问题

### 问题1: 找不到chrome设备

**解决方案**: 使用Linux桌面或Web服务器模式（见上方启动方法）

### 问题2: 没有配置Linux桌面支持

**状态**: ✅ 已添加Linux桌面支持文件

如果 `flutter run -d linux` 仍然报错，运行：

```bash
# 启用Linux桌面支持
flutter config --enable-linux-desktop

# 重新创建平台支持（会覆盖手动创建的文件）
flutter create --platforms=linux,web .

# 安装依赖
flutter pub get

# 运行
flutter run -d linux
```

### 问题3: Flutter命令找不到

确保Flutter已安装并添加到PATH：

```bash
# 检查Flutter安装
which flutter

# 如果未找到，添加到PATH（根据你的安装位置）
export PATH="$PATH:$HOME/flutter/bin"

# 或添加到 ~/.zshrc（永久生效）
echo 'export PATH="$PATH:$HOME/flutter/bin"' >> ~/.zshrc
source ~/.zshrc
```
