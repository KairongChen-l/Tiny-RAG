## 技术实现类

### Q5: 如何实现混合检索？

**回答要点**:
1. **多路召回**: 并行执行向量检索和BM25检索
2. **结果融合**: RRF（Reciprocal Rank Fusion）融合
3. **分数归一化**: 统一分数范围
4. **去重合并**: 合并重复结果
5. **Top-K选择**: 返回最终top-k结果

**代码示例**:
```go
// 并行检索
vectorResults := vectorRetriever.Retrieve(query, opts)
bm25Results := bm25Retriever.Search(query, opts)

// RRF融合
fusedResults := fuseResults(vectorResults, bm25Results, "rrf", k=60)

// 返回top-k
return fusedResults[:opts.TopK]
```

**参考**: 查看 [检索模块文档](../internal/retrieval/README.md)

### Q6: 如何实现查询重写？

**回答要点**:
1. **简单重写**: 规范化、去停用词、大小写处理
2. **LLM重写**: 使用LLM进行智能重写和扩展
3. **多查询生成**: 生成多个查询变体
4. **查询融合**: 融合多个查询的检索结果

**代码示例**:
```go
// LLM重写
rewrittenQuery := llmRewriter.Rewrite(ctx, originalQuery)

// 多查询生成
queries := llmRewriter.GenerateMultiQuery(ctx, originalQuery, count=3)

// 融合结果
results := fuseMultiQueryResults(queries, retrievalResults)
```

**参考**: 查看 [检索模块文档](../internal/retrieval/README.md)

### Q7: 如何实现增量更新？

**回答要点**:
1. **Hash计算**: 计算文档内容hash
2. **Hash比较**: 与存储的hash比较
3. **原子替换**: 如果不同，原子替换所有chunks
4. **事务保证**: 使用数据库事务保证原子性

**代码示例**:
```go
// 计算新文档hash
newHash := computeHash(doc)

// 获取存储的hash
oldHash, err := store.GetDocumentHash(ctx, docID)

// 如果不同，原子替换
if newHash != oldHash {
    err := store.ReplaceDocument(ctx, docID, newChunksWithVectors)
}
```

**参考**: 查看 [向量存储模块文档](../internal/index/README.md)
