## 关键代码片段解析

### 1. 注册表模式实现

**场景**: 管理多个Provider

**代码**:
```go
// EmbedderRegistry 管理多个embedding provider
type EmbedderRegistry struct {
    mu        sync.RWMutex
    providers map[string]Embedder
    default_  string
}

// Register 注册provider
func (r *EmbedderRegistry) Register(name string, embedder Embedder) {
    r.mu.Lock()
    defer r.mu.Unlock()
    r.providers[name] = embedder
}

// Get 获取provider
func (r *EmbedderRegistry) Get(name string) (Embedder, error) {
    r.mu.RLock()
    defer r.mu.RUnlock()
    
    embedder, ok := r.providers[name]
    if !ok {
        return nil, fmt.Errorf("embedder not found: %s", name)
    }
    return embedder, nil
}
```

**设计要点**:
- 使用 `sync.RWMutex` 保证并发安全
- 支持运行时注册，无需修改代码
- 统一的接口抽象

### 2. 混合检索实现

**场景**: 融合向量检索和BM25检索

**代码**:
```go
// RRF融合
func (h *HybridRetriever) fuseResults(
    vectorResults []RetrievedChunk,
    bm25Results []BM25Result,
    topK int,
) []RetrievedChunk {
    // 构建chunk到分数的映射
    scoreMap := make(map[string]float64)
    
    // 向量检索结果（RRF）
    for i, chunk := range vectorResults {
        rank := float64(i + 1)
        score := 1.0 / (float64(h.k) + rank)
        scoreMap[chunk.ID] += score
    }
    
    // BM25检索结果（RRF）
    for i, result := range bm25Results {
        rank := float64(i + 1)
        score := 1.0 / (float64(h.k) + rank)
        scoreMap[result.ChunkID] += score
    }
    
    // 按分数排序
    type scoredChunk struct {
        chunk RetrievedChunk
        score float64
    }
    
    scored := make([]scoredChunk, 0, len(scoreMap))
    for id, score := range scoreMap {
        // 找到对应的chunk
        chunk := findChunk(id, vectorResults, bm25Results)
        scored = append(scored, scoredChunk{chunk, score})
    }
    
    sort.Slice(scored, func(i, j int) bool {
        return scored[i].score > scored[j].score
    })
    
    // 返回top-k
    result := make([]RetrievedChunk, 0, topK)
    for i := 0; i < topK && i < len(scored); i++ {
        result = append(result, scored[i].chunk)
    }
    
    return result
}
```

**设计要点**:
- RRF算法实现
- 去重合并
- Top-K选择

### 3. 重试机制实现

**场景**: 网络错误自动重试

**代码**:
```go
func RetryWithExponentialBackoff(
    ctx context.Context,
    config RetryConfig,
    fn func() error,
) error {
    var lastErr error
    
    for attempt := 0; attempt < config.MaxAttempts; attempt++ {
        // 执行函数
        err := fn()
        if err == nil {
            return nil
        }
        
        // 检查是否可重试
        if !IsRetryableError(err) {
            return err
        }
        
        lastErr = err
        
        // 计算延迟（指数退避）
        delay := time.Duration(float64(config.InitialDelay) * 
            math.Pow(config.Multiplier, float64(attempt)))
        if delay > config.MaxDelay {
            delay = config.MaxDelay
        }
        
        // 等待或取消
        select {
        case <-ctx.Done():
            return ctx.Err()
        case <-time.After(delay):
            // 继续重试
        }
    }
    
    return fmt.Errorf("max attempts reached: %w", lastErr)
}
```

**设计要点**:
- 指数退避算法
- 错误分类（可重试/不可重试）
- 上下文取消支持

### 4. 熔断器实现

**场景**: 防止级联失败

**代码**:
```go
func (cb *CircuitBreaker) Call(fn func() error) error {
    cb.mu.Lock()
    state := cb.state
    cb.mu.Unlock()
    
    switch state {
    case StateOpen:
        // 检查是否超时
        if time.Since(cb.lastFailure) > cb.config.Timeout {
            // 进入半开状态
            cb.mu.Lock()
            cb.state = StateHalfOpen
            cb.mu.Unlock()
            return cb.Call(fn)
        }
        return ErrCircuitOpen
        
    case StateHalfOpen:
        // 允许一次尝试
        err := fn()
        cb.mu.Lock()
        if err == nil {
            cb.successCount++
            if cb.successCount >= cb.config.SuccessThreshold {
                cb.state = StateClosed
                cb.failureCount = 0
                cb.successCount = 0
            }
        } else {
            cb.state = StateOpen
            cb.lastFailure = time.Now()
            cb.failureCount = 0
            cb.successCount = 0
        }
        cb.mu.Unlock()
        return err
        
    case StateClosed:
        // 正常执行
        err := fn()
        cb.mu.Lock()
        if err != nil {
            cb.failureCount++
            if cb.failureCount >= cb.config.FailureThreshold {
                cb.state = StateOpen
                cb.lastFailure = time.Now()
            }
        } else {
            cb.failureCount = 0
        }
        cb.mu.Unlock()
        return err
    }
    
    return nil
}
```

**设计要点**:
- 三种状态转换
- 失败阈值和成功阈值
- 超时自动恢复

type OpenAIEmbedder struct {

func (e *OpenAIEmbedder) Embed(ctx context.Context, text string) ([]float32, error) {
    // OpenAI实现

// 缓存装饰器
type CachedEmbedder struct {
    embedder Embedder
    cache    Cache
}

func (e *CachedEmbedder) Embed(ctx context.Context, text string) ([]float32, error) {
    // 检查缓存
    key := cacheKey(e.embedder.Name(), text)
    if cached, ok := e.cache.Get(key); ok {
        return cached, nil
    }
    
    // 调用基础embedder
    vector, err := e.embedder.Embed(ctx, text)
    if err != nil {
        return nil, err
    }
    
    // 存入缓存
    e.cache.Set(key, vector)
    return vector, nil
}

// 使用

## 最佳实践总结

### 1. 接口设计

**原则**: 接口要小、职责单一

**好的设计**:
```go
type Embedder interface {
    Embed(ctx context.Context, text string) ([]float32, error)
    EmbedBatch(ctx context.Context, texts []string) ([][]float32, error)
    Dimensions() int
}
```

**不好的设计**:
```go
type Embedder interface {
    Embed(...)
    Cache(...)
    Retry(...)
    Metrics(...)
    // 职责过多
}
```

### 2. 错误处理

**原则**: 错误信息要详细，包含上下文

**好的设计**:
```go
return fmt.Errorf("Ollama API error (model: %s, base_url: %s): %w", 
    model, baseURL, err)
```

**不好的设计**:
```go
return fmt.Errorf("API error: %v", err)  // 信息不足
```

### 3. 并发安全

**原则**: 共享资源要加锁

**好的设计**:
```go
func (r *Registry) Get(name string) (Embedder, error) {
    r.mu.RLock()
    defer r.mu.RUnlock()
    // 读取操作
}
```

**不好的设计**:
```go
func (r *Registry) Get(name string) (Embedder, error) {
    // 没有加锁，并发不安全
    return r.providers[name], nil
}
```

### 4. 配置管理

**原则**: 所有行为都可通过配置控制

**好的设计**:
```yaml
retrieval:
  enable_hybrid: true
  fusion_method: "rrf"
  enable_rerank: true
```

**不好的设计**:
```go
// 硬编码在代码中
if fusionMethod == "rrf" {
    // 无法通过配置修改
}
```

### 5. 测试覆盖

**原则**: 关键逻辑要有测试

**好的设计**:
```go
func TestHybridRetrieval(t *testing.T) {
    // 测试混合检索
    retriever := NewHybridRetriever(...)
    result, err := retriever.Retrieve(ctx, query, opts)
    assert.NoError(t, err)
    assert.Len(t, result.Chunks, 5)
}
```

## 常见错误和避免方法

### 1. 循环依赖

**错误**:
```go
// package A
import "package B"

// package B
import "package A"  // 循环依赖
```

**避免**: 使用接口抽象，依赖接口而非具体实现

### 2. 资源泄漏

**错误**:
```go
func process() {
    db, _ := sql.Open(...)
    // 没有关闭，资源泄漏
}
```

**避免**: 使用defer确保资源释放
```go
func process() {
    db, _ := sql.Open(...)
    defer db.Close()
}
```

### 3. 并发不安全

**错误**:
```go
var counter int

func increment() {
    counter++  // 并发不安全
}
```

**避免**: 使用锁或原子操作
```go
var counter int64
var mu sync.Mutex

func increment() {
    mu.Lock()
    defer mu.Unlock()
    counter++
}
```

### 4. 错误忽略

**错误**:
```go
result, _ := apiCall()  // 忽略错误
```

**避免**: 正确处理错误
```go
result, err := apiCall()
if err != nil {
    return fmt.Errorf("api call failed: %w", err)
}
```
